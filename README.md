**🎯 Core Features**
- 📋 CRUD Operations – Aadhaar profile registration

- 🧾 Barcode Generation – CODE_128 barcode creation & retrieval  
- 🖼️ Image Upload/Retrieval – Binary storage as LONGBLOB  
- 💾 JPA Persistence – Layered controller-service-repository design
